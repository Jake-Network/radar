# First-run interview kit (#10)

Status: prepared locally; zero interviews conducted. Ten participant observations
and the seven-of-ten comprehension threshold remain unverified.

Recruit parallel-agent users across Conductor, cmux, claude-squad, Crystal and
plain worktrees. Do not send invitations until explicitly authorized. Ask consent
before screen sharing or recording; collect no source code or secrets. Use
participant aliases and allow deletion of their notes.

Allow 20 minutes per session. Before showing Radar, ask how many agents run at
once and for the last month's concrete post-merge break. Then give only the
installation link and ask them to install Radar and run `radar gate` in their
own repository. Observe without coaching. Record elapsed installation time and
first gate time separately, actual command, tool revision and repository scale.
Count `?` and `·` among displayed checks; record the denominator too. Ask them
to explain what was checked, what was not, their first question, and whether
they would use it again and why. Finally show the README first screen and ask
for a one-sentence explanation. Mark any interviewer intervention.

Use [the empty CSV](ROADMAP_USER_RESEARCH.csv). Missing observations stay empty;
do not fill them with fixtures. Rank the top three friction points after all
sessions, keeping quotes distinct from interpretation. Feed those findings into
first-run speed and wording decisions. Report sample bias and compare with the
human-labeled history benchmark; these sessions do not establish recall.
